## 7 遗留风险

| 风险项 | 风险等级 | 说明 | 应对措施 |
| --- | --- | --- | --- |
| Redis 故障 | 中 | 库存扣减、幂等校验、队列等均依赖 Redis，Redis 宕机将导致核心功能不可用 | 生产环境应部署 Redis Sentinel/Cluster |
| RocketMQ 消息丢失 | 低 | 延时消息若丢失，超时取消功能不触发 | 配置消息持久化 + 消费重试 |
| 并发下单竞态 | 低 | 极端并发下可能出现超卖 | Redis Lua 脚本已保证原子性，极端场景可加分布式锁 |
| WebSocket 多副本漂移 | 低 | K8s 重新调度时 WS 连接断开 | sessionAffinity + 客户端自动重连 |
| 库存 Redis 与 MySQL 不一致 | 低 | StockService 已对 deduct/restore 做 Redis + DB 双写，仍存在事务边界竞态（双写中间瞬间） | 定时对账任务（MVP 未实现），生产建议引入幂等补偿任务 |
| menu-service 无 Feign 客户端集成测试 | 低 | 调用方的 Feign 接口未在本模块做契约测试 | 依赖方（order-service）已通过集成测试验证调用链路 |
